POCKETOS SD CARD CONTENT

This folder contains the default PocketOS files for the matching firmware release.

INSTALL
1. Back up your SD card before changing its contents.
2. Copy/merge these files into the root of the SD card.
3. Keep your existing personal files, notes and saves.
4. Do not format the card to install this content bundle.

The apps folder contains data-only content packages for PocketOS App Manager.
This bundle does not contain executable firmware or application code.

See POCKETOS_SD_CARD.json for the exact firmware version and source commit.
