# PocketOS Guide

Welcome to PocketOS.

This package is a data-only example distributed with the matching PocketOS SD-card content bundle. It is visible in App Manager and its text resources can be opened with the read-only resource browser.

## First steps

- Keep a backup of your microSD card before firmware or content updates.
- Use the Web Flasher to install a firmware release that matches your device.
- Install the SD-card content archive from the same release by copying its files to the card root.
- Preserve personal notes, saves and files when merging the default content.

## Safety

PocketOS content packages contain data only. The firmware does not load or execute programs from this package.
