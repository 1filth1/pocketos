# PocketOS v0.1.2-rc.6

## Added
- Added an SD App Library catalogue for content/resource packages stored under `/apps/<id>/app.ini`.
- Added bounded manifest parsing, strict field validation, duplicate-key rejection, package ID/path matching, and a visible invalid-package count.
- Added package detail view with ID, version, type, path and description.

## Fixed
- Invalid, oversized, incomplete or unsupported manifests are skipped instead of being treated as valid packages.
- Directory scanning inspects at most 32 package folders, accepts at most 16 packages and reads manifests up to 768 bytes.

## Changed
- The Documents group now contains an SD App Library entry.
- This is a metadata catalogue only: it does not execute SD code, install binaries, or change existing built-in app behavior.

## Known issues
- Resource browsing, package installation/removal and app-specific runtime integration are not implemented yet.
- Only `type=content` packages are accepted in this candidate.
- Full peripheral and long-duration hardware validation remains outstanding.

## Build & package
- Target: Waveshare ESP32-S3-ePaper-3.97 (N16R8), 16 MB Flash, 8 MB OPI PSRAM.
- Arduino-ESP32 3.3.12; DIO / 80 MHz; app3M_fat9M_16MB.
- Firmware and Web Flasher bundle are generated by the repository GitHub Actions workflow.

## Upgrade
- Back up the SD card before testing.
- Existing SD data is not modified by the catalogue.
- To test, create `/apps/<id>/app.ini` on the SD card using the documented manifest format, flash RC6, then open Applications → Documents → SD App Library.

# Русский

## Добавлено
- Добавлен каталог приложений SD App Library для пакетов контента и ресурсов в `/apps/<id>/app.ini`.
- Добавлена ограниченная по размеру проверка манифеста: проверяются обязательные поля, повторяющиеся ключи, соответствие ID имени папки и число некорректных пакетов.
- Добавлен экран сведений о пакете: ID, версия, тип, путь и описание.

## Исправлено
- Неполные, слишком большие, некорректные манифесты и неподдерживаемые типы пакетов пропускаются.
- Сканирование ограничено 32 папками, 16 принятыми пакетами и манифестами до 768 байт.

## Изменено
- В раздел «Документы» добавлен пункт «SD APP LIBRARY».
- Это пока только каталог метаданных: он не запускает код с SD, не устанавливает бинарники и не меняет работу встроенных приложений.

## Известные ограничения
- Просмотр ресурсов, установка/удаление пакетов и интеграция приложений в runtime пока не реализованы.
- В этой версии принимаются только пакеты с `type=content`.
- Полная проверка периферии и длительной стабильности ещё впереди.

## Сборка и пакет
- Целевая плата: Waveshare ESP32-S3-ePaper-3.97 (N16R8), Flash 16 MB, OPI PSRAM 8 MB.
- Arduino-ESP32 3.3.12; DIO / 80 MHz; app3M_fat9M_16MB.
- Прошивка и пакет Web Flasher собираются workflow GitHub Actions репозитория.

## Обновление
- Перед тестированием сделай резервную копию SD-карты.
- Каталог не изменяет существующие данные на SD.
- Для проверки создай на SD файл `/apps/<id>/app.ini` по формату из документации, прошей RC6 и открой «Приложения → Документы → SD App Library».
