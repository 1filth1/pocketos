Установка

1
Подготовь устройствоПодключи Waveshare ESP32-S3-ePaper-3.97 (N16R8) к компьютеру USB-кабелем с передачей данных. Закрой Arduino IDE и Serial Monitor.
2
Подключи портНажми «Подключить ESP32» и выбери последовательный порт платы.
3
Запиши PocketOSПеред записью флешер повторно проверит размер и SHA-256 каждого бинарника, затем запишет файлы по адресам из манифеста.
Перед прошивкой сделай резервную копию SD-карты и всех важных данных во внутренней Flash. Новая разметка app3M_fat9M_16MB заменяет прежнюю карту разделов; старые данные SPIFFS могут стать недоступны. Не отключай USB и питание до сообщения о завершении прошивки.

Полное стирание Flash не запускается (eraseAll=false); eFuse не изменяются. Записываются только четыре образа, перечисленные в проверенном манифесте.

Требования и восстановление

Работает в Chrome / Edge на компьютере через HTTPS. Firefox и Safari не поддерживают Web Serial. Если устройство не определяется, удерживай BOOT при подключении USB, затем отпусти после появления порта. Не прошивай устройство при нестабильном питании.

После установки проверь холодный запуск, E-Ink, боковой OLED, клавиатуру/I²C, SD_MMC, аудио, Wi-Fi и питание. Успешная запись бинарников сама по себе не подтверждает работу периферии.
