Установка PocketOS прямо из браузера. Нужен Chromium-браузер с поддержкой Web Serial и USB-кабель с передачей данных.

Прошивка и таблица разделов должны происходить из одного CI-комплекта. Никакие старые бинарники не используются.

Установка

1
Подготовь устройствоПодключи собранную Waveshare ESP32-S3 ePaper к компьютеру USB-кабелем. Закрой Arduino IDE и Serial Monitor.
2
Подключи портНажми «Подключить ESP32» и выбери последовательный порт платы.
3
Запиши PocketOSЗагрузчик запишет bootloader, partition table, boot_app0 и приложение по адресам из манифеста.
Внимание: запись таблицы разделов меняет разметку Flash. Старые данные SPIFFS и содержимое Flash могут быть потеряны. Не отключай USB во время прошивки.

Требования и восстановление

Работает в Chrome / Edge на компьютере через HTTPS или localhost. Firefox и Safari не поддерживают Web Serial. Если устройство не определяется, удерживай BOOT при подключении USB, затем отпусти после появления порта. Не прошивай устройство при нестабильном питании.

После установки перезагрузка запускает первичную диагностику. Аппаратные функции (E-Ink, OLED, SD_MMC, аудио, питание) необходимо проверить на самой плате.
