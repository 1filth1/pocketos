## Release contents

The published prerelease contains:
- `application.bin`
- `bootloader.bin`
- `boot_app0.bin`
- `partitions.bin`
- `manifest.json`
- `SHA256SUMS`
- `PocketOS-firmware.zip`

The Web Flasher reads image addresses and settings from the manifest, checks each image's size and SHA-256, and writes the four images without a full-chip erase. Browser support requires Chrome or Edge with Web Serial over HTTPS.

## Hardware profile and compatibility

The CI candidate is built with Arduino-ESP32 3.3.12, the ESP32-S3 target, 16 MB Flash header, 8 MB OPI PSRAM, DIO / 80 MHz and the partition table reproduced from the user-tested firmware archive.

The original user-tested archive and the new CI candidate are not the same firmware build. The user-confirmed working archive is the known-good recovery baseline. The v0.1.1-rc.1 candidate must be tested separately before it is treated as hardware-validated.

The reference partition table maps the first 4 MiB of the physical 16 MiB Flash. This preserves the known-good NVS/SPIFFS offsets while candidate compatibility is being established.

## Branch policy

Release preparation remains in `release/pocketos-1.0`. The default `main` branch is kept separate until changes are reviewed and explicitly approved for merge. Experimental games remain in feature branches and must not be merged into the known-good release baseline without a separate review.

## Reporting test results

Record the board revision, firmware tag/commit, steps, expected and actual behavior, and serial logs or photos. Do not replace the known-good archive until the candidate has passed physical validation.
