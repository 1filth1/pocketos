# Security Policy

## Supported versions

PocketOS is experimental software. No stable release or long-term security support is currently provided.

| Version | Support |
|---|---|
| Development branch | Best-effort review |
| Pre-release builds | Use at your own risk |

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue.

Until a dedicated private security contact is published, contact the repository maintainer through GitHub's private communication options. Include:
- A concise description of the issue and its potential impact.
- Steps to reproduce, if safe to share.
- Affected commit, build or hardware configuration.
- Any suggested mitigation.

Please allow time for investigation before publicly disclosing a vulnerability.

## Scope

Security reports are especially relevant to Wi-Fi and file-transfer features, SD-card file handling, update or flashing procedures, and any code that processes data from external sources.

# Политика безопасности

## Поддерживаемые версии

PocketOS — экспериментальное программное обеспечение. Стабильного релиза и гарантированной долгосрочной поддержки безопасности пока нет.

| Версия | Поддержка |
|---|---|
| Ветка разработки | Рассмотрение проблем по возможности |
| Предварительные сборки | Использование на свой риск |

## Как сообщить об уязвимости

Пожалуйста, не публикуйте детали, позволяющие использовать уязвимость, в открытых Issues.

Пока отдельный приватный канал для сообщений об уязвимостях не настроен, свяжитесь с сопровождающим проекта через приватные средства GitHub. Укажите:
- Краткое описание проблемы и возможные последствия.
- Шаги воспроизведения, если ими безопасно делиться.
- Затронутый коммит, сборку или аппаратную конфигурацию.
- Возможный способ снижения риска.

Пожалуйста, дайте время на проверку до публичного раскрытия деталей.
